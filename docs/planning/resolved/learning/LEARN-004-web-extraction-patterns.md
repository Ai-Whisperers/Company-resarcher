# LEARN-004: Web Extraction Patterns

## Topic Overview

Web scraping is more than just downloading HTML. It involves handling dynamic content, anti-bots, and unstructured data. We need to master modern extraction patterns.

## Key Concepts

- **Headless Browsers**: Controlling Chrome/Firefox programmatically (Playwright).
- **DOM Traversal**: Finding elements via CSS/XPath.
- **LLM Extraction**: Using AI to parse messy HTML into JSON.
- **Chunking**: Splitting long pages for LLM processing.

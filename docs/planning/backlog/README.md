# Project Backlog

This directory contains the detailed backlog for the Company Researcher project, organized by category.

## Categories

- [**Critical Items**](./01-critical.md): High priority fixes and security issues.
- [**Architecture & Refactoring**](./02-architecture.md): Structural improvements and code cleanup.
- [**New Features**](./03-features.md): New capabilities to be implemented.
- [**Enhancements**](./04-enhancements.md): Improvements to existing features.
- [**Testing & QA**](./05-testing.md): Test coverage and quality assurance.
- [**Documentation**](./06-documentation.md): Documentation updates.
- [**DevOps & Infrastructure**](./07-infrastructure.md): CI/CD, Docker, and deployment.
- [**Agents & Tools**](./08-agents-tools.md): New agents and tool capabilities.
- [**Data & Storage**](./09-data-storage.md): Database and RAG implementation.
- [**Security & Compliance**](./10-security.md): Security features and compliance.
- [**User Experience**](./11-ux.md): UI/UX improvements.

## Contributing

When adding new items, please choose the appropriate category file and follow the existing format:

```markdown
### [TAG] Item Title

**Priority:** High/Medium/Low
**Description:** Brief description.
**Acceptance Criteria:**

- [ ] Criteria 1
- [ ] Criteria 2
```

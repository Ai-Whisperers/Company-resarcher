# MentorMate QA Automation Course
## Beginner to Advanced - 4 Sunday Sessions

Welcome to the MentorMate QA Automation Course! This comprehensive training program takes you from QA fundamentals to advanced automation engineering using industry-standard free tools.

## Course Overview

| Sunday | Topic | What You'll Build |
|--------|-------|-------------------|
| **1** | QA Fundamentals & Setup | Development environment, first test |
| **2** | JavaScript & Playwright | 15+ automated tests |
| **3** | Advanced & API Testing | POM framework, API test suite |
| **4** | CI/CD & Final Project | Complete automation framework |

**Total Time:** 45-60 hours (4 Sundays + homework + final project)

## Tools Used (100% Free)

- **Playwright** - Modern web automation framework
- **Postman** - API testing platform
- **GitHub Actions** - CI/CD automation
- **VS Code** - Code editor
- **Node.js** - JavaScript runtime
- **Git** - Version control

# Glossary

Definitions of terms used throughout the Company Researcher documentation and codebase.

---

## A

### Agent
An autonomous software component that performs specific research tasks. Each agent has a defined role (e.g., FinancialAgent, MarketAnalyst) and can use tools to gather and process information.

### AI Client
The abstraction layer that provides a unified interface for interacting with multiple LLM providers (OpenAI, Anthropic, Gemini, Groq, Ollama).

### Anthropic
AI company that develops Claude models. One of the supported LLM providers.

---

## B

### Backoff
A strategy for handling rate limits by progressively increasing wait times between retry attempts. Example: wait 1s, then 2s, then 4s.

### Blackboard Pattern
A design pattern where multiple agents share a common data structure (ResearchState) for communication. Each agent reads from and writes to this shared state.

### Browser Tool
A component that uses Playwright to render web pages and extract content, handling JavaScript-rendered sites and basic anti-bot measures.

---

## C

### Cache
A storage layer that saves LLM responses to avoid redundant API calls. Identified by prompt hash.

### Chain of Thought (CoT)
A prompting technique where the LLM is encouraged to show its reasoning step-by-step, improving accuracy on complex tasks.

### Claude
Anthropic's family of LLM models (Claude 3 Opus, Claude 3.5 Sonnet, etc.).

### Concurrent
Multiple operations running at the same time. The system uses concurrent execution for specialist agents in Wave 1.

---

## D

### Draft
A preliminary version of a report section generated by agents before final review and formatting.

### DuckDuckGo
A privacy-focused search engine used as a free fallback when Tavily API is unavailable.

---

## E

### Embedding
A vector (list of numbers) representation of text that captures semantic meaning. Used in RAG systems for similarity search.

### Endpoint
A specific URL path in the REST API that handles requests. Example: `/api/v1/research`.

---

## F

### Fallback
A backup option used when the primary option fails. Example: using Anthropic when OpenAI rate limits are hit.

### FastAPI
A modern Python web framework used to build the REST API.

---

## G

### Gemini
Google's family of LLM models. One of the supported providers.

### GPT-4o
OpenAI's multimodal model optimized for speed and cost. The default model for OpenAI provider.

### Graph
In this context, refers to the LangGraph StateGraph that defines the workflow of agents and their execution order.

### Groq
A company providing fast LLM inference. Supports Llama models with very low latency.

---

## H

### Hallucination
When an LLM generates false or fabricated information that sounds plausible but isn't true.

### Health Check
An API endpoint that reports the operational status of the system and its dependencies.

---

## I

### ICP (Ideal Customer Profile)
A detailed description of the type of company most likely to benefit from a product or service.

### Insight
A non-obvious conclusion derived from cross-referencing multiple data points.

### InsightGenerator
The agent responsible for synthesizing data from all specialist agents into strategic insights.

---

## J

### Jinja2
A Python templating engine used to generate consistent markdown reports from structured data.

### JSON
JavaScript Object Notation - a data format used for API communication and LLM structured outputs.

---

## L

### LangChain
A framework for building LLM applications. Provides abstractions for prompts, chains, and tool use.

### LangGraph
A library built on LangChain for creating stateful, multi-actor applications using graph-based workflows.

### LLM (Large Language Model)
AI models trained on large text datasets that can generate human-like text. Examples: GPT-4, Claude, Llama.

### LogicCritic
The QA agent that reviews reports for bias, hallucinations, and logical consistency.

---

## M

### Markdown
A lightweight markup language used for formatting text. All reports are generated in Markdown format.

### MCP (Model Context Protocol)
A protocol for standardizing how LLMs access external tools and resources.

### Mock Client
A testing utility that returns predefined responses instead of calling real LLM APIs.

---

## N

### Node
A step in the LangGraph workflow. Each node represents an agent or processing function.

### NewsAPI
A service that aggregates news articles from various sources. Used for gathering recent news about companies.

---

## O

### Ollama
Open-source software for running LLMs locally. Supports various models including Llama, Mistral, etc.

### OpenAI
AI company that develops GPT models. One of the supported LLM providers.

### Orchestrator
The main coordinator (ResearchOrchestrator) that initializes and runs the research workflow.

---

## P

### Playwright
A browser automation library used for web scraping JavaScript-rendered pages.

### Profile (CompanyProfile)
A data structure containing basic company information: name, website, industry, etc.

### Prompt
The input text sent to an LLM to generate a response.

### Provider
An external service that hosts LLM models (OpenAI, Anthropic, Google, Groq, Ollama).

### Pydantic
A Python library for data validation using type annotations. Used for all data models.

---

## R

### RAG (Retrieval-Augmented Generation)
A technique that combines information retrieval with LLM generation to provide more accurate, grounded responses.

### Rate Limiting
Restricting the number of requests to prevent overwhelming a service. Both the API and LLM clients implement rate limiting.

### Research Schema (V2)
The structured hierarchy of output reports organized into categories (00-Strategic-Context, 01-Market-Intelligence, etc.).

### ResearchState
The central state object passed through the research workflow, containing all gathered data and generated content.

---

## S

### Smart Router
A component that selects the optimal LLM model based on task complexity and cost considerations.

### Source
The origin of research data (URL, API, database). All sources are logged for auditability.

### Specialist Agent
An agent focused on a specific research domain: FinancialAgent, MarketAnalyst, CompetitorScout, BrandAuditor, SalesAgent.

### SQLAlchemy
A Python SQL toolkit and ORM used for database operations.

### State
The shared data structure that flows through the workflow, accumulating data from each agent.

### Streamlit
A Python framework for building web interfaces. Used for the research UI.

### SWOT
Strategic analysis framework: Strengths, Weaknesses, Opportunities, Threats.

---

## T

### Task
A unit of work in the API. Each research request creates a task with a unique ID that can be polled for status.

### Tavily
A search API designed for AI applications. The primary search tool.

### Template
A Jinja2 file defining the structure of output reports.

### Token
The basic unit of text that LLMs process. Roughly 4 characters = 1 token. Used for pricing and context limits.

### Tool
A capability that agents can use to interact with external systems (search, browse, fetch data).

---

## V

### Vector DB
A database optimized for storing and searching embeddings. Used in RAG implementations.

---

## W

### Wave
An execution phase in the 3-wave research model:
- **Wave 1 (Gathering)**: Specialist agents collect data in parallel
- **Wave 2 (Analysis)**: InsightGenerator synthesizes findings
- **Wave 3 (Writing)**: ReportWriter and LogicCritic produce final reports

### Workflow
The sequence of steps and agent executions that comprise a research task.

---

## Y

### yfinance
A Python library for fetching financial data from Yahoo Finance. Used by the FinancialDataTool.

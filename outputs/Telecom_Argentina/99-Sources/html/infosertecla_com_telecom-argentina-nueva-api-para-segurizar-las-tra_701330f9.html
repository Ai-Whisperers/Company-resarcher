A un año de haberse sumado a la iniciativa global Open Gateway, Telecom lanza la segunda API (interface programable de aplicaciones) para seguir aportando a la propuesta de valor de seguridad digital y antifraude, la primera vertical que la compañía decidió desarrollar en el marco de los estándares establecidos por CAMARA, el proyecto de código abierto impulsado por la Linux Fundation en colaboración con GSMA (Fuente Telecom Argentina).

Se trata de la nueva solución Number Verification que permite a los desarrolladores generar una validación simple, segura y transparente de la identidad móvil. Entre sus funcionalidades se destacan lograr una mejor experiencia en el on boarding a una APP; y el reseteo del acceso a un sitio o plataforma con un proceso encriptado y sin fricción para los clientes, prescindiendo del envío de claves por otras vías. Así, esta API busca aportar valor al ecosistema digital de la industria Fintech.

Esta es la segunda API que Telecom pone a disposición de los desarrolladores y agregadores para seguir impulsando el desarrollo del ecosistema digital. En el segundo semestre de 2023, la empresa lanzó SIM SWAP, aplicación que permite verificar la última vez que una tarjeta SIM asociada a un número móvil cambió, aportando un elevado nivel de seguridad a las transacciones realizadas mediante dispositivos móviles.

A Number Verification y SIM Swap, Telecom prevé sumar, en las próximas semanas, otras dos APIs que completan esta suite de servicios relativos a la seguridad digital. Los próximos lanzamientos serán Device Status y Device Location, dos API que permiten generar validaciones digitales georreferenciadas.

Es importante recordar que Telecom anunció en el mes de abril una alianza junto a Intraway mediante la cual se está lanzando una empresa digital conjunta que se enfocará en la creación de una solución de software cloud-native para que los proveedores de servicios de comunicaciones (CSP) de América Latina puedan acelerar la exposición y monetización de sus redes de manera segura y escalable, en el marco de los componentes y funcionalidades actuales y futuros. Las nuevas APIs de Telecom ya se están diseñando y soportando en la solución desarrollada conjuntamente entre Telecom e Intraway.

VOX Paraguay detalles

Verificación del operador y especificaciones de la red móvil

El VOX transportista de Paraguay se indica mediante códigos: 744 01 . Los siguientes ID se denominan HNI ( identidad de la red doméstica ). Este código se crea mediante la combinación de otros dos códigos de país móvil (MCC) y código de red móvil (MNC). Los primeros tres números representan el MCC y se utilizan para identificar la región de donde proviene el portado (en el siguiente ejemplo es Paraguay). Los últimos números del código HNI son iguales al MNC y este ID se proporciona para el operador de red móvil específico.

Además, VOX Paraguay tiene asignado el código de país + 595 . Este número + 595 es igual al código de llamada internacional y son simplemente los prefijos de marcación telefónica que se utilizan para llamar a los números VOX.
VOX utiliza 2 bandas GSM, 1 bandas UMTS, 1 y 0 bandas CDMA . Puede leer las bandas de frecuencia específicas en la siguiente tabla. Todas las bandas de VOX se muestran en unidades de MHz.
Otra información importante en las arquitecturas VOX Paraguay es el estándar de los protocolos utilizados. También utiliza protocolos 5 como GSM, UMTS, LTE, CDMA.

El código estándar ISO de VOX es PY .

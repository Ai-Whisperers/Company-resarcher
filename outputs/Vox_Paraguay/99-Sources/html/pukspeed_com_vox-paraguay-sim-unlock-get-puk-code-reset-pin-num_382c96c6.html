VOX Paraguay : SIM unlock | Get PUK code | Reset PIN number

The default PIN Number for all VOX Paraguay Prepaid and Postpaid mobile SIM card is unique for each mobile SIM

VOX is the major telecom network which offers high speed data connection to Paraguay customers  through Wireless, Prepaid and postpaid plans.

VOX Paraguay Mobile SIM card has an inbuilt PIN code and PUK code for security purpose. The SIM card will be blocked if you enter your PIN number wrongly for 3 times.
Then the Phone will request to enter PUK code to reset your PIN number.


You can find your VOX  PUK (Personal Unlocking Key) through following methods.
Expand the method to know more.

  • Call 021 493 640 (non-toll free number) from other network or VOX mobile phone
  • Enter the option to speak with customer care
  • Request for a PUK code and note it down
  • Enter it in your locked VOX mobile phone and reset your PIN number
  • Now your phone will be unlocked..

>Retrieve PUK Online

  • VOX Paraguay mobile has an exclusive online platform to manage the SIM related complaints.
  • Go to official webpage of VOX Paraguay mobile and click MYaccount option
  • Give your credentials and inform that your phone is locked. They will provide the PUK code after confirming that you are the owner of the SIM card
  • Note the PUK code and enter it in your locked mobile SIM card
  • Now , your mobile will ask to reset the PIN
  • Provide a new PIN and proceed to unlock your phone.
>Welcome mail /SMS option

If you have welcome mail that you got when buying the VOX Paraguay sim card, you can directly note the PUK code printed in the mail and enter it in your locked mobile phone.
Currently VOX Paraguay mobile do not provide option for obtaining PUK code through SMS.
So, Please try any one of the above methods to retrieve you PUK code.

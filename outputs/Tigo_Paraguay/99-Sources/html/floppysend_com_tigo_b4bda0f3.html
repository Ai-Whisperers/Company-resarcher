The Tigo Carrier From Paraguay is denoted by codes: 744 04. The followings IDs are called HNI (Home network identity). This code is created by the combination of two other Mobile Country Code (MCC) and Mobile Network Code (MNC). The first three numbers stand for the MCC and they are used in order to identify the region which the carried comes from (in the following example it’s Paraguay). The last numbers of the HNI code are equal with the MNC and this ID is given for the specific mobile network operator.

Besides Tigo Paraguay has assigned country code + 595. This number + 595 is equal with international calling code and it’s simply the telephone dialing prefixes used for calling Tigo numbers.
Tigo uses 2 GSM bands, 1 UMTS bands, 1 and 0 CDMA bands.. You can read the specific frequency bands in the table below. All bands of the Tigo are display in MHz units.
Another important information in Tigo Paraguay architectures is the standard of used protocols. It also uses 5 protocols such as GSM, UMTS, LTE, CDMA. The ISO standard code of Tigo is PY.

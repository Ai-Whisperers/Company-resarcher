# LEARN-002: Deep Learning for Forecasting

## Topic Overview

To implement `LSTM_AI_Stock_Predictor`, we need to understand how Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks work for time-series forecasting.

## Key Concepts

- **Sequence Data**: Data where order matters (e.g., daily stock prices).
- **LSTM Cells**: Neural network units that can "remember" long-term dependencies.
- **Lookback Window**: How many past days the model sees to predict the next day.
- **Stationarity**: Why financial data often needs differencing or normalization.

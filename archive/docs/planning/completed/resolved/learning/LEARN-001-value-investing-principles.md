# LEARN-001: Value Investing Principles

## Topic Overview

Understanding Benjamin Graham's value investing principles is crucial for building the `Intrinsic-Value-Monitor`. This involves concepts like "Margin of Safety", "Intrinsic Value", and "Mr. Market".

## Key Concepts

- **Intrinsic Value**: The true worth of a company based on its fundamentals, independent of market price.
- **Margin of Safety**: Buying at a significant discount (e.g., 50%) to intrinsic value to minimize risk.
- **Earnings Yield**: The inverse of the P/E ratio, comparable to bond yields.

# Contributing to Company Researcher System

Thank you for your interest in contributing! We welcome contributions from the community to help make this the best autonomous research platform.

## 🛠️ Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally:
    ```bash
    git clone https://github.com/YOUR_USERNAME/Company-resarcher.git
    ```
3.  **Create a branch** for your feature or fix:
    ```bash
    git checkout -b feature/amazing-feature
    ```

## 💻 Development Workflow

1.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **Code Style**:
    - We follow **PEP 8**.
    - Use `black` for formatting.
    - Use `mypy` for type checking.
3.  **Testing**:
    - Run tests before submitting: `pytest` (once implemented).
    - Verify your changes with a test run: `python main.py --name "TestCo" --industry "Tech"`

## 📝 Pull Requests

1.  Ensure your code follows the style guide.
2.  Update documentation if you change behavior.
3.  Describe your changes in detail in the PR description.
4.  Link any related issues.

## 🐛 Reporting Issues

- Use the GitHub Issues tab.
- Provide a clear title and description.
- Include steps to reproduce the bug.
- Attach logs (`research.log`) if applicable.
